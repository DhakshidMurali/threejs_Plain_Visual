# A Three.js Personal Visual Project

This project is a hands-on exploration of Three.js, to know and pratice on concepts such as:

💡 Lights

🎞️ Animation

🧱 3D Models

🎨 Textures

It’s built to understand how to build interactive and visually rich 3D scenes using WebGL through Three.js.

## 🧱 Built With

- [Three.js](https://threejs.org/)

## 🚀 Features
**Lighting**: Implementation of various light types — Point, Spotlights, etc.

**Animation**: Basic animations using requestAnimationFrame, rotation, position changes, and keyframe animations.

**3D Models**: Import and display .glb or .gltf models using the GLTFLoader.

**Textures**: Application of image-based textures on geometries to simulate real-world materials.

**Camera Controls**: OrbitControls for intuitive scene navigation.
